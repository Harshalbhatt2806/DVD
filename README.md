# 📊 Data Visualization Dashboard

A modern and interactive **Data Visualization Dashboard** built to transform raw datasets into meaningful insights through beautiful charts, graphs, and analytics. This project helps users monitor KPIs, analyze trends, and make data-driven decisions efficiently.

## 🚀 Features

- 📈 Interactive Charts (Bar, Line, Pie, Area)
- 📊 KPI Cards and Summary Metrics
- 🔍 Dynamic Data Filtering
- 📅 Date Range Selection
- 📉 Trend & Growth Analysis
- 🌙 Responsive Dashboard UI
- 📤 Export Reports (Optional)
- ⚡ Fast and User-Friendly Interface

## 🛠️ Tech Stack

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Harshalbhatt2806/DVD.git
```

### Navigate to Project

```bash
cd DVD
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

or

```bash
npm run dev
```
